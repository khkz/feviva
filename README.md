# ElRugido - Ruge Tu Fe con Verdad y Amor

Plataforma de formación en apologética cristiana que te ayuda a defender tu fe con verdad, razón y amor.

## Características

- 🎯 **Coach IA** - Practica debates de apologética con inteligencia artificial
- 💬 **Simulador de debates** - Entrena con diferentes perfiles (ateo, agnóstico, escéptico)
- 📖 **Plan Bíblico 365** - Lee la Biblia completa en un año con reflexiones diarias
- 🙏 **Oraciones guiadas** - Colección de oraciones con audio
- 📿 **Rosario interactivo** - Reza el rosario con guía paso a paso
- 🕯️ **Novenas** - Novenas con recordatorios y seguimiento de progreso
- 🌙 **Historias para dormir** - Relatos bíblicos narrados para descansar
- 📝 **Diario de gratitud** - Practica la gratitud con reflexiones IA
- 📊 **Hábitos espirituales** - Seguimiento de tus prácticas diarias
- 👥 **Comunidad** - Comparte testimonios y peticiones de oración

## Tecnologías

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion

## Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build
```
